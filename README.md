# Course Player

Нативный плеер локальных видеокурсов для macOS 13 и новее. Сборки поддерживают Apple Silicon и Intel.

[Страница выпусков и загрузок](https://github.com/sooreen/course-player-releases/releases)

Готовые сборки появятся на странице выпусков после публикации первого релиза. Скачайте DMG, откройте его и перенесите Course Player в «Программы».
Для AVI и TS нужен FFmpeg: приложение умеет находить установленную копию автоматически; файл FFmpeg можно выбрать в настройках.

Начиная с версии 0.7.0, приложение получает подписанные обновления через Sparkle. Используйте «Course Player → Проверить обновления…». Автоматические проверки включаются и выключаются в настройках. Первую версию со Sparkle нужно установить вручную.

Этот публичный репозиторий содержит готовые сборки и `appcast.xml`. Исходники хранятся отдельно. Ключи подписи, курсы, заметки и прогресс сюда не загружаются.
